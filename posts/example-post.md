## 이 파일은 예시입니다

이 저장소의 `posts/` 폴더에 마크다운(.md) 파일 하나를 추가하면, 코드 수정 없이 새 글이
자동으로 홈/카테고리 목록과 사이트맵에 반영됩니다.

가장 쉬운 방법은 `npm run dev` 실행 후 `/admin` 페이지에서 글을 작성하는 것입니다.
저장하면 이 폴더에 파일이 자동 생성되고, GitHub에도 자동으로 반영됩니다.

## frontmatter 항목 설명

- **title**: 글 제목
- **date**: 발행일 (YYYY-MM-DD)
- **description**: 목록/검색 결과에 노출될 요약
- **category**: 카테고리 (헤더 메뉴에 자동 노출)
- **tags**: 관련 태그 목록
- **draft**: true면 실제 배포 사이트에는 노출되지 않고 개발 환경에서만 보입니다

## 실제 배포 전 체크리스트

이 예시 글은 `draft: true`로 되어 있어 프로덕션 빌드에서는 자동으로 제외됩니다.
실제 글을 15~25편 이상 작성한 뒤 이 파일은 삭제하거나 `/admin`에서 지워주세요.
