# 애드센스 블로그 사이트 제작 요청서

## 프로젝트 개요

- **목적**: 구글 애드센스 승인 및 수익화를 위한 정보형 블로그 사이트 제작
- **도메인**: seniorhealth.homes (Porkbun에서 구매 완료, 네임서버/DNS 연결 가능)
- **배포 환경**: Vercel (무료 호스팅, 커스텀 도메인 무료 연결)
- **주제 방향**: 시니어/건강 관련 생활정보 (도메인명 기준, 필요 시 논의)

---

## 기술 스택 요구사항

- **프레임워크**: Next.js 또는 Astro (SEO에 강하고 정적 사이트 생성이 가능한 것으로 선택)
- **콘텐츠 관리 방식**: 마크다운(.md) 파일 기반
  - `/posts` 폴더에 파일 하나 = 글 하나
  - frontmatter로 제목, 날짜, 태그, 설명(description) 관리
  - 코드 수정 없이 파일 추가만으로 새 글 발행 가능해야 함
- **배포**: GitHub 저장소 연동 → Vercel 자동 배포 (main 브랜치 푸시 시 자동 반영)
- **도메인 연결**: Vercel 프로젝트 설정에서 seniorhealth.homes 연결 (A 레코드/CNAME은 Porkbun DNS에 설정)

---

## SEO 필수 세팅

- `sitemap.xml` 자동 생성 (예: `next-sitemap` 패키지 활용)
- `robots.txt` 설정 (구글 크롤러가 사이트 전체를 읽을 수 있도록)
- 각 글 페이지에 `title`, `description` 메타 태그가 동적으로 삽입되어야 함
- 반응형 디자인 필수 (모바일 트래픽 비중이 높음을 감안)
- 페이지 로딩 속도 최적화 (이미지 최적화, 불필요한 스크립트 최소화)

---

## 애드센스 승인을 위한 필수 요구사항

> 아래는 구글 애드센스 승인 심사에서 핵심적으로 보는 3가지 요소입니다.
> 사이트 설계 및 개발 시 반드시 반영해 주세요.

### 1. 사이트 완성도

- 사용자가 사이트에 들어왔을 때 길을 잃지 않는 구조
- 상단 메뉴, 카테고리 구성이 명확해야 함
- 빈 카테고리(글이 없거나 한두 개만 있는 경우)는 감점 요인 → 카테고리는 콘텐츠가 실제로 채워진 것만 노출
- 모바일에서도 가독성이 좋아야 함 (반응형 필수)

### 2. 사이트 신뢰도(투명성)

- 구글 봇에게 "이 사이트는 무엇을 다루고, 누가 운영하는지" 투명하게 보여줘야 함
- **필수 페이지 (반드시 구현)**:
  - 운영자 소개
  - 사이트 소개
  - 문의 페이지 (이메일 또는 문의 폼)
  - 개인정보 처리방침 (애드센스 쿠키/광고 데이터 수집 고지 포함)
  - 이용 가이드/약관
- 이 페이지들은 상단 메뉴 또는 푸터에서 쉽게 접근 가능해야 함

### 3. 콘텐츠의 차별성

- AI가 생성한 글을 복사해서 붙여넣기만 하는 행위는 지양
- 가독성 고려: H2 태그 구조화, 문단 간 적절한 공백
- 검색 사용자가 실제로 원하는 정보를 담은 독창적인 콘텐츠

## 애드센스 신청을 위한 추가 기술 요소

- `public/ads.txt` 파일을 루트 경로에 올릴 수 있는 구조로 미리 설계 (승인 후 코드만 교체하면 되도록)
- 애드센스 검토 코드를 `<head>`에 삽입할 수 있어야 함 (Next.js 기준 `_document.tsx` 또는 layout 파일)
- 광고 삽입 위치를 자유롭게 조정할 수 있는 구조 (본문 중간, 사이드바 등)

---

## 콘텐츠 운영 목표 (참고용)

- 신청 전 최소 15~25편 이상의 독창적인 글 확보
- 편당 본문 1,000자 이상 (이상적으로는 1,500자 이상)
- 하나의 명확한 주제 축 유지 (여러 주제 혼재 시 전문성 약화로 평가될 수 있음)

## 기타 참고사항

- 사이트 제작자는 UX/UI 기획 경험이 있으며, Vercel을 통한 배포 경험 보유 (이전 포트폴리오 사이트 제작 시 사용)
- 워드프레스 대신 직접 개발 방식을 선택한 이유: 월 정기 비용 절감(Vercel 무료 호스팅) 및 커스터마이징 자유도
